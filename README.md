# CSE-Git-Practice

## Project Overview
This repository serves as a foundational development workspace for the **B.Tech Computer Science and Engineering (CSE)** curriculum at Lovely Professional University. It tracks initial coursework experiments, modular Python scripts, and version control workflows aligned with corporate placement preparation for an **AI/ML Engineer** role at Tata Consultancy Services (TCS).

## Purpose & Scope
- **Version Control Mastery:** Implementing Git branch management, clean commit structures, and issue tracking.
- **Foundational Programming:** Housing core algorithm implementations, data structure drills, and Python utilities.
- **Academic Alignment:** Supporting coursework deliverables for CSE111 and subsequent computer science laboratory practice.

## Tools & Technologies
- **Language:** Python 3.12
- **Version Control:** Git & GitHub CLI
- **Operating Environment:** Windows 11 / Command Line

## Repository Structure
- `demo/`: Directory containing introductory scripts and Git practice files.
- `README.md`: Architectural documentation and project overview.
